Руководство пользователя


Данное приложение "Математическая викторина" является увлекательной и интересной викториной для всех возрастов!


Цель викторины заключается в что чтобы проверить свои знания в области математики


Поле викторины состоит из четырех строк в центре в правом верхнем углу расположен таймер, снизу по центру расположена кнопка старта викторины


Проходящий пишет ответы в специальных полях для ответа
